# Agro Coronel Suárez — versión modular

## Estructura
- `index.html`: contenido de la página.
- `css/base.css`: colores, tipografía, contenedor y botones.
- `css/header.css`: header y navegación.
- `css/hero.css`: hero.
- `css/services.css`: servicios.
- `css/history.css`: nuestra historia.
- `css/identity.css`: misión, visión y valores.
- `css/team.css`: equipo.
- `css/campaign.css`: CTA del Portal Clientes.
- `css/contact.css`: contacto y mapa.
- `css/footer.css`: footer.
- `css/animations.css`: animaciones.
- `css/responsive.css`: media queries.
- `js/main.js`: JavaScript del sitio.
- `imagenes/equipo/`: fotos del equipo extraídas del HTML.

## Qué tocar para cada cambio
- Textos: `index.html`
- Colores globales: `css/base.css`
- Hero: `css/hero.css`
- Servicios: `css/services.css`
- Historia: `index.html` + `css/history.css`
- Equipo: `index.html` + `css/team.css`
- Mobile/tablet: `css/responsive.css`

Las rutas existentes como `imagenes/hero.png`, `imagenes/history_image.png`
y `imagenes/servicio1.png` se mantienen sin cambios.
